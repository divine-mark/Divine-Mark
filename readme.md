## Course Overview

The labs cover the core of object-oriented programming in Java:

- **Labs 1–3:** Foundations — classes, objects, constructors, encapsulation.
- **Labs 4–6:** The four pillars — inheritance, polymorphism, abstraction.
- **Labs 7–9:** Robust code — exceptions, generics, collections, enums, records.
- **Labs 10–11:** Real applications — file I/O, streams, design patterns, and a
  full mini-project (Library Management System).

## Requirements

- **JDK 17 or later** (JDK 21 recommended).  
  Records, pattern matching for `instanceof`, and text blocks need Java 16+.
